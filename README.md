# AgriKnowledge Hub — Complete Agricultural Information and Farming Management Platform

**Tagline:** *"Knowledge for Better Farming. Technology for a Better Harvest."*

AgriKnowledge Hub is an all-in-one digital agricultural technology platform engineered to bring comprehensive, verified farming knowledge, practical management tools, transparent market pricing, certified inputs directories, educational courses, and AI agronomic advisory into one accessible, production-oriented application.

Kenya serves as the initial launch market, featuring Kenyan agro-ecological zones, 47 counties, certified seed varieties, bimodal rainfall calendars (Long & Short Rains), Kenyan Shilling (KES) budgeting, and bilingual support in English and Kiswahili.

## 🌾 Platform Architecture & Core Modules

### 1. Crop Farming Module
- Comprehensive 31-point agronomic profiles covering:
  - **Cereals:** Hybrid Maize (*H614D, H628, SC Duma 43*), Wheat, Rice, Sorghum, Millet.
  - **Legumes:** Common Beans (*Rosecoco, Nyota high-iron*), Green Grams (*Ndengu*), Cowpeas.
  - **Vegetables:** Tomatoes (*Kilele F1, Anna F1*), Onions, Cabbages, Kale (*Sukuma Wiki*), Spinach, Carrots.
  - **Roots & Tubers:** Irish Potatoes (*Shangi, Dutch Robjin, Unica*), Sweet Potatoes, Cassava.
  - **Fruits:** Hass Avocado, Mangoes, Bananas, Passion Fruit.
  - **Cash & Industrial:** Tea, Coffee, Sugarcane, Sunflower.
  - **Fodder Crops:** Brachiaria (*Basilisk, Piata*), Napier Grass, Lucerne (*Alfalfa*).
- 31 dimensions per guide: botanical name, family, economic importance, climatic zones, altitude (m ASL), temperature & rainfall, soil pH & drainage, certified varieties with maturity days, planting calendars (Long & Short Rains), seed rate per acre, spacing geometries, plant population stand, land preparation, fertilizer schedules (basal DAP/NPK, top-dress CAN), water demand, weed control, pests, diseases, harvest maturity indicators, expected yield ranges, post-harvest drying (13.5% safe storage moisture), market opportunities & KES profitability models, common mistakes to avoid, and authoritative KALRO/KEPHIS citations.

### 2. Livestock Farming Module
- Deep species profiles covering:
  - **Dairy Cattle:** Friesian, Ayrshire, Jersey (zero-grazing unit dimensions, TMR rations, dry matter 3% body weight, AM-PM AI estrus breeding, mastitis teat dipping).
  - **Beef Cattle:** Boran, Sahiwal, Zebu.
  - **Poultry:** Commercial Broilers (*Cobb 500*), Commercial Layers (*Isa Brown*), Improved Kienyeji (*KALRO Kienyeji, Kenbro, Kuroiler*). Complete day-by-day vaccination schedule (Marek's, Gumboro IBD, Newcastle ND, Fowl Pox).
  - **Dairy & Meat Goats:** Toggenburg, Saanen, Boer, Galla goats (raised slatted floors, CCPP vaccination).
  - **Aquaculture:** Nile Tilapia & African Catfish pond and liner systems.
  - **Beekeeping (Apiculture):** Modern Langstroth hives, Kenya Top Bar Hives (KTBH), honey harvesting.
  - **Sheep, Pigs, Rabbits & Camels.**

### 3. Soil Health, Fertilizers & Irrigation
- Soil classification in Kenya: Red volcanic loam (*Nitisols*), Black cotton soil (*Vertisols*), Sandy loam.
- Step-by-step 5-step field soil sampling protocol and directory of certified testing laboratories in Kenya (KALRO NARL, Cropnuts, MEA).
- Agricultural liming guide for acidic highland soils (pH < 5.2) to unlock fixed phosphate.
- Irrigation systems: Drip irrigation kits, overhead sprinklers, and lined rainwater harvesting farm ponds.

### 4. Crop Pests, Diseases & Symptom Helper
- Searchable agricultural problem database: Fall Armyworm, Maize Lethal Necrosis (MLND), Tomato Late Blight, Bacterial Wilt, Tuta Absoluta, Striga weed.
- Interactive Diagnostic Assistant / Photo Symptom Helper: select crop, observed symptom, or upload photo to receive differential diagnosis, confidence score, and IPM action plan.
- Responsible chemical guidance specifying registered active ingredients, Pre-Harvest Intervals (PHIs), Re-entry intervals (REI), and mandatory PPE.

### 5. Weather, Climate & Planting Calendars
- Location-aware Kenyan weather intelligence for all 47 counties.
- Official Kenya Meteorological Department (KMD) seasonal outlooks.
- Interactive Crop Planting Calendar Generator producing week-by-week operational timetables.

## 🛠️ Technology Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend Server:** Node.js, Express, `server.ts` entry point running Vite middleware in dev.
- **AI Integration:** `@google/genai` TypeScript SDK using `gemini-3.8-flash` on server side.
- **State & Context:** React Context API (`AuthContext`, `FarmContext`, `LanguageContext`).
- **Data Persistence:** Local storage synchronization for farm records, fields, and language preferences.

## 🚀 Setup & Installation Instructions

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` (optional for local dev):
```bash
# GEMINI_API_KEY: Required for live Gemini AI responses.
# When not set, the platform uses its built-in agronomic knowledge engine.
GEMINI_API_KEY="your_gemini_api_key_here"
```

### 3. Launch Development Server
```bash
npm run dev
```
The full-stack application will launch at `http://localhost:3000`.

### 4. Build for Production
```bash
npm run build
npm start
```
